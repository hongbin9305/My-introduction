AI 전처리는 언제 도움이 되는가?

모델을 비교해야 하는 학습자와 실무자가 원본·표준화 조건의 실측 결과를 확인하고, 어떤 조건을 선택할지 근거를 정리하도록 돕습니다.

같은 데이터라도 전처리가 언제나 정확도를 높이지는 않습니다. 1,797건의 손글씨 숫자 데이터에 대한 20회 실제 실험 결과를 살펴보세요. 이 도구는 모델을 새로 학습시키지 않고, 이미 검증한 실험 결과를 비교하고 판단을 돕습니다.

1분 사용 방법

① 결과 살펴보기원본 조건 A와 표준화 조건 B의 평균 정확도를 비교합니다.
② 회차 선택하기막대를 눌러 특정 반복 실험의 오분류 개수를 확인합니다.
③ 선택 근거 저장결론을 확인하고 검증 메모를 TXT로 저장합니다.

이 결과로 무엇을 결정할까요?

논문에서 표준화 조건의 평균 정확도가 낮았습니다.

논문의 해석 한계
원본과 표준화 모두 gamma='scale'이어서 실제 RBF 커널 매개변수도 달라집니다. 이 비교는 두 파이프라인의 차이이며, 표준화만의 인과 효과를 입증하지 않습니다. 다른 데이터에 그대로 일반화하지 마세요.

내 실험 결과도 비교하기 (선택 기능)

직접 실행한 두 조건의 동일 분할별 오분류 건수가 있다면 아래에 붙여넣어 비교할 수 있습니다. 여기서 새 모델 학습은 수행하지 않습니다. 입력은 브라우저 안에서만 처리하고 서버에 전송하지 않습니다.

CSV 열: run,raw_errors,standardized_errors,test_n · 각 run에 해당하는 오분류 건수는 0 이상, test_n 이하여야 합니다.

논문과 결과의 관계

가설: 표준화를 하면 같은 RBF-SVM의 평균 분류 정확도가 높아질 것이다. 실제 20회 비교에서는 원본 조건의 평균 정확도가 더 높아 가설이 지지되지 않았습니다. 따라서 사용자가 전처리를 자동으로 선택하지 않고, 같은 분할에서 성능을 검증한 뒤 결정하도록 이 앱을 만들었습니다.
