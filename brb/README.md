2026-11-03 하홍빈의 T10 논문 「AI 전처리는 언제 도움이 되는가?」에서 측정된 scikit-learn Digits 1,797건의 20회 RBF-SVM 분류 결과를 보여주는 **브라우저 기반 비교 도구**입니다.

- 포트폴리오: https://hongbin-br-a-portfolio.vercel.app

## 누구를 어떻게 돕는가
모델 전처리를 선택해야 하는 학습자와 실무자가 **원본·표준화 파이프라인의 실측 정확도와 회차별 오분류를 비교**하고, 자신의 데이터로 다시 계산하여 판단 근거를 TXT로 보관할 수 있게 돕습니다.

## 할 일 세 가지
1. 첫 화면의 20회 평균 정확도(A 98.97%, B 98.01%)와 평균 차이(−0.96%p)를 확인합니다.
2. 각 회차 막대를 선택해 원본·표준화 오분류 건수와 정확도를 확인합니다.
3. '선택 근거 TXT 저장'을 눌러 결론과 연구의 한계를 다운로드합니다.

### 추가 검증
- '내 실험 결과도 비교하기'에 아래를 입력하고 분석 버튼을 누릅니다.
```csv
run,raw_errors,standardized_errors,test_n
1,5,10,450
2,4,12,450
```
- 결측값, 문자, 범위 밖 오분류 건수, 중복된 run, 1,000회 초과 입력은 오류 메시지로 처리합니다. 기존 비교값은 유지됩니다.
- '논문 실측값으로 초기화'를 누르면 논문의 20회 자료로 복귀합니다.
- 사용자 CSV는 브라우저에서만 파싱합니다. 서버에 업로드하지 않습니다.
- 환경변수/API 키가 필요 없는 정적 HTML/JavaScript 앱입니다.

## 결과 설명의 한계
- 논문은 **표준화의 순수 인과효과**를 구분하지 못했습니다. `gamma='scale'`의 실효 매개변수도 입력 분산에 따라 바뀝니다.
- 논문에서 성능 차이가 관찰됐다는 사실과, 그 차이의 원인을 설명하는 가설을 구별합니다.
- 앱은 실측값을 보여주는 도구입니다. 브라우저에서 학습을 다시 수행하는 앱이 아닙니다.

## 연구 수치 원본 비교
- 20회 × 2조건 = 40행.
- 평균 오분류 A 4.65개, B 8.95개 (매회 평가 450건).
- 평균 정확도 A 98.96666667%, B 98.01111111%; 차이 B−A −0.95555556%p.
- B 우세 0회 · 동률 1회 · A 우세 19회.
- 데이터 저작권과 출처: scikit-learn Digits, UCI Optical Recognition of Handwritten Digits.
