AI 전처리는 언제 도움이 되는가?

네트워크·보안 교육에서 배운 검증 절차를 적용한 손글씨 숫자 분류 20회 반복 실험

초록

특성별 표준화가 모든 머신러닝 분류에서 성능을 높이는지 공개 데이터로 비교하였다. scikit-learn 손글씨 숫자 데이터 1,797건, 64개 픽셀 특성, RBF-SVM을 사용하였다. 학습·평가 데이터는 동일한 층화 무작위 20개 분할로 구성하고, 원본 픽셀 조건과 StandardScaler 적용 조건을 비교했다. 원본 정확도는 평균 98.97%, 표준화 적용 정확도는 98.01%로, 후자가 0.96%p 낮았다. 이는 원래 개선을 예상했던 가설을 지지하지 않는 결과다. 분산 기반 gamma 설정의 혼동 가능성 때문에 표준화의 독립적인 인과 효과를 입증하지는 못한다.

1. 연구 배경 및 가설

네트워크, Linux, 웹 인증 실습에서 '설정했다'와 '검증했다'의 차이를 경험했다. 이를 머신러닝에서도 확인하기 위해 다음 가설을 세웠다. 손글씨 숫자 분류에서 특성 표준화를 적용하면 동일한 RBF-SVM 분류의 평균 정확도가 높아질 것이다. 보안 분야의 실제 탐지 성능은 이번 자료만으로 판단하지 않는다.

2. 방법

scikit-learn의 load_digits 데이터셋 1,797건을 사용하였다. 학습 75%, 평가 25%이며 20회에서 원본 조건과 표준화 조건에 같은 학습·평가 분할을 적용했다. StandardScaler는 학습 데이터에만 적합시킨 뒤 평가 데이터에 적용하여 정보 누출을 방지하였다. 분류기는 RBF-SVM이며 정확도와 F1을 비교하였다.

3. 결과

조건평균 정확도
A · 원본 픽셀98.97%
B · 특성 표준화98.01%
B−A−0.96%p

20회 중 표준화 조건이 더 나은 경우 0회, 동률 1회, 낮은 경우 19회였다. 원래의 개선 가설은 이 실험에서 지지되지 않았다.

4. 논의와 한계

gamma='scale'에서는 입력 데이터 분산에 따라 실제 gamma 값이 달라진다. 따라서 관찰된 정확도 차이를 표준화 자체만의 영향으로 결론 내릴 수 없다. 본 결과는 특정 숫자 이미지 데이터, 모델 설정, 20개 분할에 한정되며, 네트워크 침입 탐지 성능이나 다른 데이터셋의 결과로 일반화할 수 없다.

5. 결론

전처리 사용 여부는 관례보다 비교 검증으로 결정해야 한다. 이 실험에서 표준화 조건의 정확도는 예상보다 낮았으며, 원본과 코드·예측 결과를 보관해 가설이 기각된 사실을 그대로 남겼다.
